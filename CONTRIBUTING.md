# Contributing

1. `git config core.hooksPath .githooks`
2. Read `spec/` (highest version is current). No code lands without an approved spec and a task.
3. Branch: `feat/short-slug` from `main`. Commit with Conventional Commits and cite task IDs.
4. Open a PR into `main`; the title is a Conventional Commit and the checklist is filled in.

Rules in full: `.claude/rules/`. Decisions: `docs/adr/`.
